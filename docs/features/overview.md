# Product feature overview

This document is the clean-room product reference. Implement against these feature requirements, not historical code.

## Product goal

Provide a phone-friendly local web client for Codex with a minimal but reliable workflow:
- open the app from a browser on the local network
- bootstrap the current viewer session
- continue work in a workspace/thread context
- resume, stream, and answer text-first Codex thread activity without copying the upstream UI

## Product constraints

- mobile-first UI
