# Contributing to My-Code-X

Thanks for your interest in contributing.

## Getting Started

- Read the README first.
- Install dependencies with `npm install`.
- Make sure `codex app-server` is available on your `PATH`.

## Development

Useful commands:

```sh
npm run start
npm run status
npm run stop
npm run lint
npm test
```

## Guidelines

- Keep changes small and focused.
- Add or update tests when behavior changes.
- For UI changes, include screenshots in the PR.
- Do not include unrelated refactors in the same PR.

## Pull Requests

Please describe:

- what changed
- why it changed
- how it was tested

## Security

Do not report security issues in public issues or PRs.
Please follow `SECURITY.md`.
