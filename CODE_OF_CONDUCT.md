# Code of Conduct

Please be respectful and constructive in all project spaces.

## Expected Behavior

- Be kind and professional.
- Give helpful feedback.
- Focus on the technical issue.
- Respect different experience levels and viewpoints.

## Unacceptable Behavior

- Harassment or personal attacks
- Discrimination or hateful language
- Trolling, hostility, or repeated disruption
- Sharing private or sensitive information

## Enforcement

Maintainers may edit, remove, or restrict content or participation that violates this code of conduct.
