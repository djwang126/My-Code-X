# Security Policy

Thanks for helping keep My-Code-X safe.

## Reporting a Vulnerability

Please do not report security issues in public issues, pull requests, or discussions.

Report them privately to the maintainer.

Include:

- a short description
- impact
- reproduction steps
- any relevant logs or screenshots

## Notes

Please keep in mind:

- LAN mode exposes the app to your local network.
- Cloudflare quick tunnels are public by default and don't support SSE.

## Supported Versions

Security fixes are prioritized for the latest version on the default branch.
